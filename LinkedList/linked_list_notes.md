# Linked list

## Singly linked list
A singly linked list is a sequence of nodes. Each node stores a value and a pointer to the next node. The nodes can live at different addresses in memory. The next pointers determine their order.

## What is a doubly linked list?
Each node stores a value and two pointers. next points to the following node, and prev points to the preceding node. We’ll keep both head and tail so we can start at either end.
